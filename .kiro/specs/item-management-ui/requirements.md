# Requirements Document

## Introduction

Система управления предметами для аукционного бота с возможностью отключения покупки предметов и просмотра актуальных цен с иконками. Функция должна интегрироваться в существующий веб-интерфейс и работать с текущей системой предметов.

## Glossary

- **Item_Manager**: Система управления предметами
- **Target_Item**: Предмет из списка targetItems для отслеживания и покупки
- **Web_UI**: Веб-интерфейс для управления ботом
- **Price_Data**: Информация о ценах предмета (buyPrice, sellPrice, absoluteMinUnitPrice)
- **Item_Icon**: Визуальное представление предмета (иконка Minecraft)
- **Purchase_Status**: Статус возможности покупки предмета (включен/отключен)

## Requirements

### Requirement 1: Просмотр списка предметов

**User Story:** Как пользователь, я хочу видеть список всех отслеживаемых предметов с их иконками и ценами, чтобы контролировать работу бота.

#### Acceptance Criteria

1. WHEN пользователь открывает страницу управления предметами, THE Item_Manager SHALL отобразить список всех Target_Item
2. WHEN отображается Target_Item, THE Item_Manager SHALL показать иконку предмета, название, текущие цены и статус покупки
3. WHEN Price_Data доступна для предмета, THE Item_Manager SHALL отобразить buyPrice, sellPrice и время последнего обновления
4. WHEN Price_Data недоступна для предмета, THE Item_Manager SHALL показать "Цены не загружены"
5. THE Item_Manager SHALL отображать иконки предметов на основе поля 'name' из Target_Item

### Requirement 2: Управление статусом покупки

**User Story:** Как пользователь, я хочу включать и отключать покупку отдельных предметов, чтобы контролировать поведение бота.

#### Acceptance Criteria

1. WHEN пользователь нажимает на переключатель предмета, THE Item_Manager SHALL изменить Purchase_Status предмета
2. WHEN Purchase_Status изменяется на "отключен", THE Item_Manager SHALL сохранить изменение и предотвратить покупку этого предмета
3. WHEN Purchase_Status изменяется на "включен", THE Item_Manager SHALL сохранить изменение и разрешить покупку этого предмета
4. THE Item_Manager SHALL визуально отличать включенные и отключенные предметы
5. THE Item_Manager SHALL сохранять состояние Purchase_Status между перезапусками

### Requirement 3: Отображение актуальных цен

**User Story:** Как пользователь, я хочу видеть актуальные цены предметов, чтобы понимать рыночную ситуацию.

#### Acceptance Criteria

1. WHEN отображается Target_Item, THE Item_Manager SHALL показать buyPrice, sellPrice и absoluteMinUnitPrice
2. WHEN цены обновляются, THE Item_Manager SHALL автоматически обновить отображение без перезагрузки страницы
3. WHEN цена изменилась с последнего просмотра, THE Item_Manager SHALL выделить изменение визуально
4. THE Item_Manager SHALL отображать время последнего обновления цен для каждого предмета
5. THE Item_Manager SHALL форматировать цены с разделителями тысяч для удобства чтения

### Requirement 4: Интеграция с веб-интерфейсом

**User Story:** Как пользователь, я хочу управлять предметами через тот же веб-интерфейс, что и остальными функциями бота.

#### Acceptance Criteria

1. THE Item_Manager SHALL интегрироваться в существующий Web_UI как новая секция
2. THE Item_Manager SHALL использовать тот же дизайн и стили, что и остальной Web_UI
3. THE Item_Manager SHALL быть доступен через новую вкладку или раздел в главном интерфейсе
4. THE Item_Manager SHALL работать с существующей системой аутентификации и авторизации
5. THE Item_Manager SHALL обновляться в реальном времени вместе с остальными данными интерфейса

### Requirement 5: API для управления предметами

**User Story:** Как система, мне нужен API для управления статусом предметов, чтобы веб-интерфейс мог взаимодействовать с бэкендом.

#### Acceptance Criteria

1. THE Item_Manager SHALL предоставить API endpoint для получения списка всех Target_Item с их статусами
2. THE Item_Manager SHALL предоставить API endpoint для изменения Purchase_Status конкретного предмета
3. WHEN API получает запрос на изменение статуса, THE Item_Manager SHALL валидировать запрос и обновить состояние
4. THE Item_Manager SHALL возвращать актуальные Price_Data через API
5. THE Item_Manager SHALL логировать все изменения статусов предметов для аудита

### Requirement 6: Отображение иконок предметов

**User Story:** Как пользователь, я хочу видеть иконки предметов (незеритовый шлем, слиток и т.д.), чтобы быстро идентифицировать предметы визуально.

#### Acceptance Criteria

1. THE Item_Manager SHALL отображать иконку для каждого Target_Item на основе поля 'name'
2. WHEN поле 'name' содержит стандартное название предмета Minecraft, THE Item_Manager SHALL показать соответствующую иконку
3. WHEN иконка для предмета недоступна, THE Item_Manager SHALL показать иконку по умолчанию
4. THE Item_Manager SHALL использовать иконки размером 32x32 пикселя для оптимального отображения
5. THE Item_Manager SHALL кэшировать иконки для улучшения производительности

### Requirement 7: Фильтрация и поиск предметов

**User Story:** Как пользователь, я хочу искать и фильтровать предметы по названию или статусу, чтобы быстро находить нужные предметы в большом списке.

#### Acceptance Criteria

1. THE Item_Manager SHALL предоставить поле поиска для фильтрации предметов по displayName или searchKeyword
2. THE Item_Manager SHALL предоставить фильтры для отображения только включенных или отключенных предметов
3. WHEN пользователь вводит текст в поиск, THE Item_Manager SHALL показывать только соответствующие предметы в реальном времени
4. THE Item_Manager SHALL сохранять состояние фильтров и поиска при навигации
5. THE Item_Manager SHALL показывать количество найденных предметов
